# 🏥 Integrated-Patient-Care-Management-Platform  
A comprehensive hospital management system that centralizes patient care, staff coordination, room allocation, billing, and medical record tracking — all through a unified and interactive platform built using **Python**, **Streamlit**, and **SQLite**.

## 🚀 Features  

 **Patient Management** – Register and manage patient details including admission, discharge, and personal information.  
 **Doctor & Staff Management** – Maintain detailed information about doctors, nurses, and receptionists, including roles, qualifications, and experience.  
 **Room & Facility Allocation** – Assign rooms to patients, manage occupancy, and track nurse supervision and equipment allocation.  
 **Pharmacy & Equipment Tracking** – Maintain real-time records of medicines, medical equipment, and inventory status.  
 **Medical Records** – Record diagnosis, prescriptions, and treatment history for each patient efficiently.  
 **Billing System** – Generate, manage, and view billing information for treatments, medicines, and room usage. 
 **Dynamic Database Viewer** – View, search, and filter all hospital data dynamically with a user-friendly interface.  
 **Interactive Web App** – A responsive and dark-themed web interface designed using Streamlit and SQLite for simplicity and performance.  

---

## 💡 Use Cases  

 **Doctors & Nurses** – Access and update patient medical history, treatment, and prescriptions.  
 **Receptionists** – Register new patients, assign rooms, and manage hospital data efficiently.  
 **Hospital Administrators** – Track hospital resources, billing, and staff performance all in one place.  
 **Students / Developers** – Learn real-world database integration, CRUD operations, and Streamlit-based app development.  

---

## 🛠 Tech Stack  

**Frontend / UI**: Streamlit (Python Framework)  
**Database**: SQLite  
**Backend Logic**: Python (sqlite3, pandas, datetime)  

---

## 📖 Usage  

1️⃣ Run the database setup file:  
python main.py
2️⃣ Launch the Streamlit web application:
streamlit run app_web.py
3️⃣ In the web app:
➕ Use Add Data to insert new records into any hospital table.
📊 Use View Database to explore, search, and filter hospital records.
4️⃣ The local database file hospital.db automatically stores all records securely.
